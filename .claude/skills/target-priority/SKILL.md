# 타깃 우선순위 구현 가이드

## 구조
- `ash_e_priority/core.py`: ROS 의존 없는 순수 로직(점수 계산, 상태 머신). 단위 테스트 대상.
- `ash_e_priority/node.py`: 구독/발행만 하는 얇은 ROS2 래퍼.
- `config/priority.yaml`: 모든 가중치·임계값.

## 점수 예시 (설계서 수식이 있으면 그것을 우선)
`score = w_state·S_state + w_dist·S_dist + w_conf·S_conf + w_center·S_center + w_stay·S_stay`
- `S_state`: `smoking`=1.0, `holding`=0.7. 지금 피우는 사람이 곧 꽁초가 생길 사람이므로 `holding`보다 높게 둔다는 기본 가정이다(사용자 의도와 다르면 조정).
- `S_dist`: 가까울수록 높게(접근 비용 감소). 유효 거리 범위 밖은 0.
- `S_conf`: 인식 신뢰도.
- `S_center`: 화면 중심에 가까울수록 높게(회전 비용 감소).
- `S_stay`: 같은 위치에 머무는 시간. 걷는 사람은 따라잡기 어려우므로 정지한 사람을 선호한다.

## 타깃 선택 상태 머신
`IDLE → TRACKING(target) → (LOST | OUT_OF_RANGE) → 다음 후보 선택 또는 IDLE`
- **히스테리시스**: 현재 타깃을 바꾸려면 새 후보 점수가 현재 점수보다 `switch_margin` 이상 높아야 한다. 점수가 비슷한 두 사람 사이에서 로봇이 왔다 갔다 하는 것을 막기 위해서다.
- **이탈 판정**: 거리 `max_range` 초과 또는 `lost_timeout` 동안 미관측이면 타깃을 해제하고, 그 ID에 `cooldown` 동안 재선택 금지를 건다(깜빡임 방지).
- **재선택**: 해제 즉시 남은 후보 중 최고 점수를 고른다. 후보가 없으면 IDLE.
- 입력이 `input_timeout` 이상 끊기면 IDLE로 전환한다.

## 발행
현재 타깃(ID, 위치, 상태, 점수)과 전체 후보 순위 목록을 설계서의 메시지로 발행한다. 순위 목록은 디버깅과 시각화(RViz marker)에 쓴다.

## 테스트 필수 항목
다수 대상 순위 정렬, 거리·상태 가중치 효과, 히스테리시스 유지, 이탈 후 다음 대상 전환, 쿨다운, 입력 끊김 IDLE. 순수 로직이므로 pytest로 Windows에서도 실행 가능하다.
